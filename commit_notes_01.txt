
This PR bootstraps `ytingbackend` as a Vercel-native Next.js backend focused on the first auth milestone: user registration, login, phone verification, token refresh, and protected user reads. It aligns the API surface and project structure with the requested Supabase/PostgreSQL schema and mobile-app REST usage.

- **Backend scaffold**
  - Added a minimal Next.js + TypeScript project layout for serverless deployment on Vercel
  - Added `vercel.json`, TypeScript/ESLint config, and environment-variable template
  - Added a lightweight root page documenting the exposed backend endpoints

- **Auth and token flow**
  - Implemented `POST /api/auth/register` to create users against the existing `users` table, hash passwords, and create phone verification tokens
  - Implemented `POST /api/auth/login` with email/username/phone identifier support, failed-login tracking, and temporary account locking
  - Implemented `POST /api/auth/refresh-token` for refresh-token based session renewal
  - Implemented `POST /api/auth/verify-phone` to validate OTPs and mark phone verification state

- **Protected user APIs**
  - Implemented `GET /api/users/profile` for the authenticated caller
  - Implemented `GET /api/users/[id]` with self/admin access control
  - Added `GET /api/health` for deployment/runtime health checks

- **Shared auth infrastructure**
  - Added Supabase server client helper
  - Added JWT signing/verification utilities for access and refresh tokens
  - Added OTP generation helpers
  - Added typed auth/database models and response sanitization to avoid leaking sensitive fields

- **Request protection**
  - Added Next.js middleware for JWT verification on `/api/users/*`
  - Middleware propagates verified identity/admin context via request headers to the API handlers

- **Deployment and usage docs**
  - Added `instructionA.md` with setup, environment, deployment, and REST usage examples tailored for local development and Vercel deployment

Example of the implemented API contract:

```ts
// POST /api/auth/login
{
  "identifier": "demo@example.com",
  "password": "StrongPass123!"
}
```

```json
{
  "accessToken": "<jwt>",
  "refreshToken": "<jwt>",
  "user": {
    "user_id": "uuid",
    "email": "demo@example.com",
    "username": "demo-user",
    "phone_verified": false
  }
}
```
